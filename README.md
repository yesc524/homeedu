# 나의 옷장 QUEST

의복 마련 계획을 세우는 학생용 보드게임 웹앱입니다. 학년·반·번호·이름을 각각의 칸에 입력하고 마련할 옷을 고르면, 귀여운 옷 일러스트가 여섯 미션 칸을 따라 이동합니다.

## GitHub Pages에 올리기

저장소 맨 위 위치에 있는 index.html, styles.css, app.js 세 파일을 올리세요. 기존 세 파일이 있다면 같은 이름으로 덮어씁니다. GitHub의 Add file → Upload files → Commit changes를 사용하세요. 압축파일 자체를 올리면 실행되지 않으므로 압축을 풀어 세 파일을 올려야 합니다. 잠시 뒤 저장소의 GitHub Pages 주소를 새로고침하세요.

GitHub Pages에서는 서버를 실행할 수 없어 자동 점검(규칙 기반, AI 아님)이 제공됩니다. 직업인을 선택해 점검을 읽고, 성찰과 수정 계획을 기록한 뒤 브라우저의 PDF로 저장을 사용할 수 있습니다.

## 실제 AI 피드백을 사용하는 Node 서버

Node.js 20 이상에서 OPENAI_API_KEY를 서버의 환경 변수로 설정하고 npm start를 실행합니다. http://localhost:3000 으로 접속하세요. 이때 public 폴더의 화면이 열리고, 서버가 실제 AI 피드백을 요청합니다. API 키를 GitHub 파일이나 브라우저 코드에 넣지 마세요.

## 구성

- STEP 1 필요성, 2 예산, 3 활용도, 4 소재, 5 관리 가능성, FINAL 종합 미션
- 각 STEP에 서술형 2개와 선택형 1개. 모든 문항에 고려 질문 3개
- 시작할 때 옷의 이름을 짓고, 옷장 탐정·가격표 뒤집기·착용 달력·라벨 찾기·관리 상황 카드·선택의 갈림길을 체험
- 미션을 마치면 보드의 옷 일러스트가 이동하고 주제별 그림이 있는 근거 카드가 쌓임. 가격 총액, 연간 예상 착용 횟수와 1회 착용 비용을 자동 계산
- 선택 활동인 지속가능성 BONUS
- 직업인 10명 중 한 명의 관점으로 점검, 성찰, 수정·보완, PDF 저장
- 내용은 브라우저 localStorage에 자동 저장. 공용 기기에서는 사용 후 사이트 데이터를 삭제하세요.
- PDF에는 학년·반·번호·이름, 옷의 이름, 미니 활동 결과와 미션 답변이 출력됩니다.

GitHub Pages의 자동 점검은 실제 AI 피드백이 아닙니다. 학생에게 이 차이를 화면에 명시합니다. 답변의 사실 확인은 학생과 교사가 다시 해야 합니다.

## GitHub Pages의 피드백 오류

GitHub Pages 주소에서는 앱이 자동으로 정적 사이트임을 감지하여 AI 서버 호출 대신 규칙 기반 자동 점검을 표시합니다. 화면에 Unexpected token 같은 오류가 보이면 저장소 맨 위의 app.js를 최신 파일로 교체하고 페이지를 새로고침하세요. 실제 AI 피드백을 받으려면 Node 서버와 서버 측 API 키 설정이 필요합니다.

## Google 스프레드시트로 제출

마지막 화면에 PDF 저장과 스프레드시트 제출을 함께 제공합니다. 대상 Google 시트에 제출을 연결하려면 google-apps-script/설정방법.md의 순서대로 Code.gs를 배포한 뒤, index.html의 window.CLOTHING_SHEET_WEB_APP_URL에 웹 앱 주소를 입력하세요. 설정 전에는 제출 버튼이 비활성화됩니다. 제출 내용은 **학생 제출** 탭에 저장되고, **채점표** 탭에 규칙 기반 **자동 예비점수** 18개와 영역별 5점·총 30점이 입력됩니다. 근거의 정확성과 설명의 타당성은 교사가 **평가 기준** 탭을 보며 확인·수정합니다. 기존 빈 점수는 Apps Script의 `fillMissingScores` 실행으로 채울 수 있습니다. 같은 제출 ID로 다시 제출하면 답안은 갱신되지만 기존 점수는 유지됩니다. 지속가능성 BONUS는 총점에서 제외됩니다. PDF 저장은 연결 여부와 상관없이 사용할 수 있습니다.
